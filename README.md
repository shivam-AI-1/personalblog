# Shivam Personal Blog

A personal blog website showcasing my journey from high school to college life, featuring blog posts, portfolio, and contact information.

## 🌟 Features

- **Home Page**: Welcome section with featured articles
- **Blog Section**: Collection of blog posts about academic journey and personal growth
- **Portfolio**: Showcase of projects and technical skills
- **Contact Form**: Get in touch section
- **Responsive Design**: Mobile-friendly layout
- **Clean UI**: Modern and minimalist design

## 📁 Project Structure

```
shivam blog/

```

## 🚀 Getting Started

### Prerequisites

- A modern web browser (Chrome, Firefox, Safari, Edge)
- A local web server (optional, for development)

### Installation

1. Clone the repository:
```bash
git clone https://github.com/yourusername/shivam-blog.git
cd shivam-blog
```

2. Open the project:
   - Simply open `index.html` in your web browser, or
   - Use a local development server:
   ```bash
   # Using Python
   python -m http.server 8000
   
   # Using Node.js (http-server)
   npx http-server
   ```

3. Navigate to `http://localhost:8000` in your browser

## 🎨 Customization

### Changing Colors
Edit the CSS files in `css/css/` to modify the color scheme.

### Adding Blog Posts
1. Create a new HTML file or modify `blogpost.html`
2. Add the article entry to `blog.html`
3. Update the featured articles section in `index.html`

### Updating Portfolio
Edit `portfolio.html` to:
- Update project cards
- Modify skills section
- Change social media links

## 📱 Responsive Design

The website is designed to be responsive across different screen sizes. The layout adapts to:
- Desktop (1024px and above)
- Tablet (768px - 1023px)
- Mobile (below 768px)

## 🚢 Deployment

This project is configured for deployment on Netlify:

1. Push your code to GitHub
2. Connect your repository to Netlify
3. The `netlify.toml` file handles routing configuration
4. Your site will be live automatically

### Manual Deployment

You can also deploy to other platforms:
- **GitHub Pages**: Push to `gh-pages` branch
- **Vercel**: Connect your GitHub repository
- **Any static hosting service**: Upload the files
